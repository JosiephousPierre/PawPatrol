## 🔄 How to Apply These Coordinates

### Method 1: Reset Application Data (RECOMMENDED)

1. Open your PAWPATROL application
2. Navigate to **Municipality Management** page
3. Click the **"Reset Data"** button (top right)
4. Click **"Confirm"** in the popup dialog
5. ✅ **Done!** - OpenStreetMap coordinates now loaded

### Method 2: Clear Browser Storage

1. Open the application in your browser
2. Press **F12** to open Developer Tools
3. Go to **Application** tab
4. Expand **Local Storage** in the left sidebar
5. Click on your application's domain
6. Find and **right-click** on `pawpatrol_municipalities`
7. Select **"Delete"**
8. **Close** Developer Tools
9. **Refresh** the page (F5 or Ctrl+R)
10. ✅ **Done!** - System reloads with new coordinates

### Method 3: Hard Refresh

1. **Close ALL browser tabs** of the application
2. **Clear browser cache**:
   - Chrome: Ctrl + Shift + Delete
   - Select "Cached images and files"
   - Click "Clear data"
3. **Open new browser tab**
4. Navigate to application
5. ✅ **Done!** - Fresh data loaded
