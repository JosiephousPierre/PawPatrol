   • Stores: riskLevel, infectedDogs/Cats/Humans, vaccinatedDogs, lastUpdated

2. REAL-TIME SYNC MECHANISMS
   
   a) Cross-Tab Sync (Different tabs/windows):
      → Browser native "storage" event
      → When MACO updates → LAAK tab auto-refreshes
   
   b) Same-Tab Sync (Same browser instance):
      → Custom event "pawpatrol_regional_risk_updated"
      → Dashboard updates immediately after simulation

3. AUTOMATIC TRIGGERS
   
   When Simulation Completes:
   • useSimulationEngine.js → appStore.saveAllData()
   • localStorage.js → updateRegionalRiskData()
   • Dispatches events → All tabs receive update
   
   When Page Loads:
   • LandingPage.vue → refreshRegionalRiskData() on mount
   • DashboardPage.vue → refreshRegionalRiskData() on mount
   • Merges latest regional data with local municipalities
   
   When Data Changes (Real-Time):
   • Store listens via setupCrossTabSync()
   • Auto-merges regional data when event fires
   • Municipalities array updates reactively → UI refreshes

TECHNICAL DETAILS:

Architecture:
  • Event-driven synchronization (no polling)
  • Reactive Vue updates (automatic UI refresh)
  • Timestamp-based conflict resolution (latest wins)
  • Merge strategy preserves local demographic data

Performance:
  • Storage events: Native browser, zero latency
  • Custom events: In-memory, microsecond latency
