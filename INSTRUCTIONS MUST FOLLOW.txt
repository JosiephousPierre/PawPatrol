# PAWPATROL Prototype Development Instructions

## Project Overview

Create a web-based research prototype called **PAWPATROL (Hybrid Quantum-Classical Framework for Adaptive Rabies Transmission Modeling and Vaccination Optimization).**

The purpose of the system is to simulate rabies transmission across the municipalities of Davao de Oro and demonstrate adaptive vaccination recommendations based on the proposed research framework.

This application is a **frontend-only research prototype** intended for academic demonstration and presentation.

## Requirements

- Use dummy/simulated data only.
- Store all application data using the browser's Local Storage.
- Do NOT implement a backend server.
- Do NOT use a database.
- Do NOT implement a real Deep Reinforcement Learning (DRL) model.
- Implement a rule-based adaptive vaccination decision engine that mimics the behavior of the proposed DRL.
- Do NOT implement quantum computing.
- Focus on demonstrating the workflow presented in the research paper.
- The application must be deployable as a static website (Vercel or Netlify).

# Adaptive Vaccination Decision Module (DRL Prototype)

Create a frontend rule-based adaptive vaccination engine.

This module represents the proposed DRL component from the research.

IMPORTANT

Do NOT use:

- Machine Learning
- TensorFlow
- PyTorch
- AI APIs
- Deep Learning Libraries

Instead,

implement deterministic rule-based logic.

Inputs

- Current infection counts
- Municipality risk level
- Neighbor municipality infection status
- Vaccination coverage

Outputs

- Recommended Municipality
- Vaccination Percentage
- Priority
- Decision Reason

Example Rules

Rule 1

IF Infection Rate > 70%

THEN

Recommend

Vaccinate 90%

Priority: High

--------------------------------

Rule 2

IF Neighbor Municipality is Infected

Increase Priority

--------------------------------

Rule 3

IF Infection Rate < 20%

Monitor Only

--------------------------------

Rule 4

IF Vaccination Resources are Limited

Prioritize Highest Risk Municipality

Persist recommendations using Local Storage.

# Important Notes

This project is a research prototype.

The objective is to demonstrate the workflow described in the research paper rather than build a production-ready epidemiological system.

The Adaptive Vaccination Decision Module is implemented as a rule-based engine that simulates the behavior of the proposed Deep Reinforcement Learning component.

The application should run entirely on the frontend using Local Storage and should be easy to deploy as a static website for research demonstration.
