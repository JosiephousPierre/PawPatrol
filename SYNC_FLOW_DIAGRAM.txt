KEY MECHANISMS:

1. localStorage.setItem()
   └→ Triggers "storage" event in OTHER tabs (cross-tab sync)

2. window.dispatchEvent(CustomEvent)
   └→ Triggers custom event in SAME tab (same-tab sync)

3. store → setupCrossTabSync()
   └→ Listens to BOTH events
   └→ Auto-merges regional data
   └→ Vue reactivity updates UI

4. Page Load (onMounted)
   └→ refreshRegionalRiskData()
   └→ Ensures latest data on page load
