# User Interface Requirements

The application must have a clean, modern, and responsive interface suitable for a research presentation.

## Layout

Use a **sidebar navigation layout** after entering the system.

The sidebar should remain visible on desktop and be collapsible on smaller screens.

The main content should be displayed beside the sidebar.

Suggested navigation items:

🏠 Dashboard

📍 Municipality Management

🧪 Simulation

📊 Results

📖 About

---

## Dashboard

The dashboard should display summary cards and graphical visualizations.

Dashboard Cards

- Total Municipalities
- Total Dog Population
- Total Cat Population
- Total Human Population
- Current Infected Dogs
- Current Infected Cats
- Current Infected Humans
- Current Simulation Day

Dashboard Graphs

Display summary charts such as:

- Infection Trend
- Population Distribution
- Vaccination Coverage

These charts should update automatically whenever simulation data changes.

---

## Results Page

The Results page should serve as the primary visualization page for the simulation.

Include the following sections:

### Interactive Map

Display all municipalities in Davao de Oro using Leaflet.js.

Features

- Municipality markers or boundaries
- Municipality color indicators
- Municipality popup information
- Risk visualization

---

### Charts

Use Chart.js to visualize simulation results.

Include at least the following charts:

- Dog Infection Trend
- Cat Infection Trend
- Human Infection Trend
- Vaccination Coverage
- Municipality Risk Comparison

Charts should update dynamically while the simulation is running.

---

### Adaptive Vaccination Recommendation

Display the current recommendation generated by the rule-based DRL prototype.

Show:

- Recommended Municipality
- Vaccination Percentage
- Priority Level
- Decision Reason

---

### Simulation Log

Display the simulation timeline.

Example

Day 1

Maco outbreak detected.

Day 3

Vaccination recommended.

Day 5

Transmission reached Mawab.

Day 8

Outbreak slowing.

---

## Design Guidelines

Use a modern dashboard design.

Requirements

- Responsive layout
- Sidebar navigation
- Card-based UI
- Interactive charts
- Interactive map
- Consistent spacing
- Soft shadows
- Rounded corners
- Professional color palette
- Smooth page transitions
- Loading indicators where appropriate

Recommended Colors

Primary

Blue

Secondary

Green

Warning

Orange

Danger

Red

Background

Light Gray or White
